## Durable capture contract

`CaptureStore` owns private/provisional capture files. Canonical immutable JSON
records and a monotonic identity/revision inventory are authoritative; SQLite
postings and receipts are rebuildable. New-store initialization is published
atomically under a parent lock. Record fsync precedes inventory publication,
which precedes searchable index/receipt commit. Startup adopts validated
post-save/pre-inventory crash orphans but fails on missing/changed acknowledged
records, even if the index is also missing. It never reconstructs lost source
text from token postings.

Receipts separate saved/searchable/promoted; `created` describes this call, not
global concurrent store growth. Changed idempotent retries fail. Keys are scoped
by trusted visibility. Corrections preserve originals and exact visibility;
derivatives retain their evidence group and become stale when an ancestor is
superseded. Hidden operator lineage cannot change GM-visible claim status.
Captures cannot be promoted or made public by an input field. Tokenless or wholly
unqueryable text is rejected rather than falsely called searchable.

`MemoryService` explicitly routes `domain='captured'` to the private reader,
normalizes source/revision/status/lineage, and bounds direct reads without
including a search excerpt outside the requested range. Missing stores report
unavailable; no fallback to public/native campaign sources is invented.

## Controlled legacy import

`python -m unification.import_legacy --source PATH --store PATH --archive PATH`
is an explicitly local operator command. The exact original JSONL and each row
are immutable private snapshots. Row-byte identities make append/reorder/retry
stable. All original fields survive in snapshots; confidence/source/channel
labels do not become permission, canon or independent corroboration.

The real pilot accounts for **17/17 rows**, **17 saved/searchable**, **0 promoted**,
**0 malformed**, and an idempotent replay adds **0 records**. Shared service
query-and-exact-read checks verify each record and originating revision; the
opt-in operator CLI returns matching evidence. Public search/get are denied,
and a GM context cannot read operator-only imported rows. Scratch index removal
and rebuild preserves all sources. Measured initial saved-to-searchable maximum
was approximately **15.7 ms**, not a production freshness claim.

The data volume rejected hard-link snapshot publication before any row import.
That failure receipt is preserved. Snapshot publication now uses cooperative
directory locking, file fsync and same-directory atomic rename; controlled import
and replay on the actual data volume passed.

A metadata-only private review queue records **301** legacy campaign/consolidated
source files with revisions. They are queued, not semantically reviewed, indexed,
publicly approved or promoted. Unique-claim count remains unknown.

## Concrete first canary and boundary

The implemented operator CLI is:

```sh
python3 -m unification.capture_cli --store PRIVATE_PILOT_STORE search --q QUERY
python3 -m unification.capture_cli --store PRIVATE_PILOT_STORE get capture/RECORD_ID
python3 -m unification.capture_cli --store PRIVATE_PILOT_STORE save \
  --origin-file PRIVATE_ORIGIN_JSON --idempotency-key UNIQUE_KEY --text-file PRIVATE_TEXT
```

It has no audience override, promotion verb, server or default store. It is a
local operator entrypoint, **not** a remote tool/session authority grant. The
public shadow CLI remains public; do not relabel its default unconfigured hybrid
mode as the deployed native service. Native public pilot and specialist routing
have separate U2 shared-service evidence.
