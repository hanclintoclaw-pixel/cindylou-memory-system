## Goal and invariants

One access/write contract over authoritative files and rebuildable local indexes. Reuse
OpenClaw hybrid retrieval; keep exact SR3 page/equipment specialists. No new external
database, no duplicate canonical knowledge corpus. Prioritize quick, accurate live-game
answers: rules, campaign wiki, then the existing edition-checked web escalation.

- Wiki owns campaign canon; workspace notes own private operations; original conversations
  are evidence, accessed ONLY with host-authorized session tools; books own SR3 rules.
- Dossier/dreams/summaries are attributed views, never independent corroboration.
- Enforce audience on search AND direct reads before snippets leave the service.
- Public answer context cannot inherit private rights from the operator's identity.
- Unknown visibility defaults private; unknown source/adapter state fails explicitly.
- No full mixed-agent database restore into a live box. Source restore + memory reindex is
  the normal rollback. A full DB snapshot is forensic/recovery input, not a live rollback command.
- Never delete originals, sweep unrelated dirty files, bulk-promote generated facts, silently
  fall back to legacy private roots, or alter current live answers before gates pass.
- Code/docs: code tier. Snapshots, question evidence, facts, results, checkpoints: private data
  tier. No credentials, copyrighted corpus text, or GM-private evidence in git/wiki.

### U1 — Contract, registry, access policy (isolated; no live caller switch)

Deliverables: versioned request/result types, source registry, policy boundary, adapters and
negative tests. Fields: stable ID, revision hash, source/parent evidence IDs, visibility,
knowledge domain, confirmed/provisional/disputed/superseded, citations and partial coverage.
Trust context comes from transport/host authority, never an arbitrary `audience` JSON field.
An unprivileged local CLI can offer public reads; private operator CLI is an explicitly
local trusted entrypoint, not reusable over an unauthenticated public HTTP endpoint.
Resolve paths strictly (no basename fallback, traversal, symlink escape, hidden/archive
paths). Only registry-approved documents enter ranking; inaccessible content cannot affect
snippets or direct-read results. Recheck policy at read time and fail on stale revisions.
Start with a restrictive public wiki directory allowlist; this is a candidate classification,
not proof every file is public. Review embedded private metadata and classify exceptions.
Keep sessions unavailable in the standalone adapter until host-issued authority is integrated.
Gate: real negative/positive tests, symlinks/traversal, missing context, stale refs, bounded
reads, invalid schemas; no private snippets even when the query exactly matches a secret.
Rollback: unused isolated module; production has not changed.

### U3 — Reliable capture, disconnected facts and reconciliation

Gate: save→search→correction tests; forced interruption and idempotent rerun; no duplicated
source evidence; every saved fact has a matching reader and truthful receipt.

### U5 — Retirement and operational handoff

Only after successful live-table evidence plus rollback checks: disable old redundant
services/search routes, archive legacy indexes/prototypes with manifest, remove misleading

Gate: no disconnected writers/callers; one documented authority per domain; native and

## Acceptance matrix

- Saved facts: original 17 accounted for, each imported/rejected with reason; retries add zero.
- Audience: no forbidden snippet, ID, count-derived content or direct read in public cases.
- Provenance: citations point to actual source/revision; derivative copies do not corroborate.
- Consistency: equivalent context/query/revision yields equivalent evidence across callers.
- Recall: known entity/deep fact can be retrieved; missing facts return unknown, not invented.
- Rules: SR3 only; citations preserved verbatim; uncertain edition/source/page means decline.
- Reliability: backend unavailable vs empty vs stale are distinguishable; bounded timeouts.
- Recovery: source + config rollback loses no accepted new writes; indexes rebuildable.
- Live latency: retrieval times separated from model/audio; p50/p95 + sample count recorded.
