## Completed preparation

`unification.canary_tool` is a real client of the approved API, not a second
retrieval backend. Its single JSON input selects `health`, `search` or
revision-bound bounded `get`. Its tool output has `content`, `details` and
`isError`; the text and structured evidence agree. Source citations, exact
revisions, provisional/authority labels, evidence grouping and source coordinates
are preserved. Coverage is always partial. Candidate scores are not answer
confidence; the same two reviewed public sections remain the only public scope.

Disabled calls return before stdin/token/socket I/O. Enabled requests reject
unknown fields, authority/configuration injection, invalid types and excessive
query/read/body budgets before token access. The trusted local caller chooses
only an unprivileged loopback port and owner-only token-file path. No host/URL,
audience, registry, partition, source expansion, write or fallback option exists.
The client shares API token-file owner/type/permission checks, never prints the
token, does not use proxy environment variables or follow redirects, and uses
one connection per invocation with no retry.

The 12-second default network deadline covers connect, response headers and
body together, including slow drip. It uses a socket shutdown watchdog, not a
series of independently reset read timeouts. Local token validation and process
startup are outside that budget. A response is capped at 1 MiB, requires one
Content-Length and JSON type, and cannot use transfer encoding. The socket closes
and watchdog joins on success/failure. HTTP framing is interpreted by the standard
library; this is not independent detection of bytes after Content-Length.

Denied/stale/unavailable/invalid request remain distinct; healthy empty is not
unavailable. Error bodies and exception text are not relayed. Success must have
the expected public campaign caller, ready backends, valid revision/citation
and provenance, and the expected operation shape. Health/get cannot smuggle
search hits; unknown top-level/evidence fields and extra bounded-get excerpts
fail closed. Get checks its requested ID/revision, line budget and source metadata.

## Optional OpenClaw plugin candidate

`integrations/openclaw-memory-canary/` contains a dependency-free ESM plugin,
manifest, package declaration and matching tool schema. It registers only
`cindylou_memory_canary` as **optional**, with a version-2 tool factory. Plugin
config `enabled` defaults false. Import, discovery, registration and disabled
execution perform no token/network I/O or child creation. Sandboxed contexts
and contexts without an invocation currency guard do not construct the tool.

The factory always binds public output, never deriving private rights from
sender/owner/session identity. Its guard runs before starting work and before
returning evidence. Cancellation kills the child and waits for closure. It uses
the fixed absolute local Python interpreter in isolated mode, a minimal child
environment, ignored stderr, a 15-second child watchdog and a 4-MiB output cap.
Arguments carry a token **path**, not the credential. The child result must have
one matching text/details envelope, the correct exit status and error flag,
partial public coverage, and no extra output blocks or wrapper fields.

**Packaging constraint:** the plugin is not a standalone directory install.
It resolves `unification` two levels above its own directory. Export committed
