  unavailable. There is no dispatch implementation to enable with an operator,

  private directory. It rejects protected-path overlap, symlink parents and unsafe
  permissions; writes only single-component JSON names through an identity-bound
  directory descriptor with no-follow/exclusive creation. Existing output is not
  overwritten. This is a **cooperative output guard**, not confinement of arbitrary
  Python code or proof that production writes are denied.
- Two-phase synthetic supervisor pins fresh content/size/mtime identities of all
  explicitly enumerated scratch source/code/registry/partition files. It rejects
  generation drift before/after a control, changed query/context, replay and
  unknown/revoked/expired local test tokens. These tokens are deliberately not host

  revision-matched bounded passage containing literal fixture terms. A document ID

  and unknown remain distinct; final answer correctness and loss are unassessed.
  This literal fixture rubric is not used to adjudicate historical private claims.
- `scripts/memory_unification_isolation.py`: opt-in synthetic controls only. The
  default and every real lane exit unavailable before opening supplied inputs,
